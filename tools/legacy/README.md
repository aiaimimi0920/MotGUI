# 历史工具，仅作源码参考

这里保留旧 tools 分支的 `mklink.py`、protobuf 定义及插件导出配置副本。

**不要直接运行 `mklink.py`。** 它硬编码了旧目录，并在创建软链接前递归删除目标路径。当前工程已经合并为单目录，不需要该链接脚本；保留它是为了追溯旧开发流程，不是推荐操作。

`plugin-export-presets.cfg` 是插件分支的历史配置快照，未随目录整理改写。活动工程中的对应文件位于 `../../backup_export_presets.cfg`，其中相对导出路径已随项目根目录迁移调整；旧绝对模板路径仍待重新审阅。

没有复制旧编辑器、导出模板和 Spout DLL。它们仍可从外部完整 GitHub mirror 的 `tools` 分支找回，但版本兼容性尚未验证。
