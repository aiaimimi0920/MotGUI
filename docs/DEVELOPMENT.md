# 客户端开发状态

目标职责：桌面形象、窗口、动画、文字/语音交互、设置界面、游戏加入提示、呈现切换与恢复、本地执行支持。

## 当前事实

- `project.godot` 和所有客户端脚本、场景、资源保留旧内容，本轮未升级引擎。
- `plugin/`、`external_service_adapter/`、`external_service/` 已全部移到独立 MotPlugin 仓库。
- Godot 的 `res://` 只指向本工程根目录，不能天然引用另一个仓库。旧加载器及配置中的插件路径尚未调整，这是本次允许的结构迁移断点。
- 根 `export_presets.cfg` 与 `backup_export_presets.cfg` 仍包含历史模板绝对路径；相对导出路径也依赖工程检出位置，独立检出后须重新配置，未验证打包。
- 定制 `ColorScheme` 等资源类型、Godot 4.4 配置与旧引擎之间的兼容性未验证。
- 启动代码仍有历史认证、插件下载及京东/淘宝测试调用。本轮未启动旧应用或业务服务。

后续应决定客户端与插件的装配和加载方式，再恢复运行。不要用手工复制插件或机器专属软链接形成第二份维护源。

`tools/legacy/mklink.py` 含旧绝对路径和删除目标目录的逻辑，仅保留作历史参考，不应直接运行。
