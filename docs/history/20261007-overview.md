# mot_gui：客户端与现有 Godot 工程

当前工程入口为本目录的 `project.godot`，主场景为 `core/system/main.tscn`。

目标职责包括桌面形象、窗口、动画、文字与语音入口、设置界面、连接提示、呈现切换与恢复，以及必须在客户端执行的本地操作。智能规划不应长期依赖 GUI 才能运行。

## 过渡状态

本轮保持旧工程完整，不拆改 `.gd` 文件：`addons/`、`core/`、`gui/`、资源、场景和三个旧插件目录一起迁入本目录，因此原有 `res://` 引用保持有效。

这里的 `core/` 是旧 Godot 工程的内部代码，不等于仓库一级的 `mot_core/`。这里仍包含历史认证、插件加载和服务调用逻辑；这不代表它们未来都属于图形界面职责。

旧插件继续以以下目录作为唯一源码来源，不能同时在 `mot_plugin/` 维护另一份副本：

- `plugin/`
- `external_service_adapter/`
- `external_service/`

后续迁出需要一起处理资源路径、打包和运行时加载。本轮没有建立链接目录、源码同步或副本生成机制。

## 当前限制

尚未验证当前引擎运行兼容性。旧平台认证、插件下载、测试调用、绝对构建路径和缺少 Python 依赖锁定等问题未在目录整理中修复。详见 [仓库入口](../START_HERE.md)。
